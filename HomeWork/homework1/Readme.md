# Домашнее задание 1: Иммутабельный класс

## Задача
Реализовать иммутабельный класс, который содержит поле с изменяемым классом.

## Решение
Класс `ImmutableClass` демонстрирует принципы создания неизменяемых объектов:

### Ключевые моменты:
1. Все поля объявлены как `private final`
2. Отсутствуют сеттеры (нет способов изменить состояние после создания)
3. Класс объявлен как `final` (запрет наследования)
4. **Защитное копирование в конструкторе** — создаём копии изменяемых объектов (Department, List, Date)
5. **Защитное копирование в геттерах** — возвращаем копии, а не оригиналы
6. Использование `Collections.unmodifiableList()` для дополнительной защиты списка

### Изменяемые поля внутри иммутабельного класса:
- `Department` — изменяемый класс (есть сеттеры)
- `List<String>` — изменяемая коллекция
- `Date` — изменяемый объект даты

### Тестирование
Метод `main()` содержит тест, который:
1. Создаёт иммутабельный объект
2. Пытается изменить оригинальные объекты
3. Проверяет, что состояние Employee не изменилось
